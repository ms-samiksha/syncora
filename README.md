# Syncora 📚✨
A web-based study room platform built to support collaborative learning with features like rooms, dashboard, progress tracking, and simple productivity tools.

## 🚀 Features
- User authentication (Login/Signup)
- Create and join study rooms
- Room dashboard UI
- Productivity tools (To-do, quiz bot pages, summarizer bot page, motivator bot page)
- Firebase integration

## 🛠 Tech Stack
- HTML, CSS, JavaScript
- Firebase (Auth/Database)

## 📂 Pages Included
- `index.html` (landing)
- `login.html`, `signup.html`
- `create-room.html`, `room.html`, `room-list.html`
- `dashboard.html`, `progress.html`
- `study-rooms.html`
